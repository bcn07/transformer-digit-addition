# results/

Everything here is committed output. Nothing in this directory is generated at import time.

```
sweep/                  the frac_train sweep: weight_decay=1.0 at five training fractions
                        x three seeds, 100k steps each. The dataset behind the
                        generalisation results.
controls/               weight_decay=0.0 at frac_train=0.015, one per seed. Matched
                        partners for the three sweep runs at that fraction, identical
                        in every other respect including the data split.
history_L1_*_s42.json   single runs driven from notebooks/digit_addition.ipynb
checkpoints/*_best.pt   best-test-accuracy weights for the four analysed models
circuit_formation.json  per-head ablation damage, zero and mean, at 50 checkpoints
universality.json       per-head ablation damage for the four best checkpoints
```

Naming is `history_L{n_layers}_wd{weight_decay}_ft{frac_train}_s{seed}.json`, matching
`TrainArgs.run_name` in `train.py`, so any file maps back to the command that made it. Seed 42
means the run came from the notebook; seeds 0-2 came from `train.py` on the cluster or the
command line.

Two schemas coexist: `train.py` writes `{"config": ..., "history": ...}` and the notebook's save
cell writes the history dict bare. The loading code accepts either. The older files also predate
per-sequence accuracy, so `test_seq_accuracy` is absent from some of them.

Per-step checkpoints (`*_step*.pt`, 50 files, ~40 MB) are gitignored. `circuit_formation.json` is
the analysis output computed from them, and `notebooks/carry_circuit.ipynb` falls back to it when
they are absent. Regenerate them with the command in that notebook.

## Figures

Every figure is regenerated by a cell in one of the two notebooks, named in the last column.
Rerunning that cell overwrites the png, so check `git status` afterwards.

| file | from | generated by |

| `sweep_frac_train.png` | `sweep/` — generalisation against each run's memorise-only ceiling | `digit_addition.ipynb` §4 |
| `runs_L1.png` | the `history_L1_*_s42.json` runs | `digit_addition.ipynb` §3 |
| `circuit_formation.png` | `circuit_formation.json` — ablation damage across training, both methods | `carry_circuit.ipynb` |
